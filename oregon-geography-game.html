Projection: equirectangular with cos(44°) correction. Bounds lon −124.716 to −116.314, lat 41.843 to 46.421, viewBox 0 0 1000 757.4. One function projects lon/lat → x/y for drawing; its exact inverse converts taps back. Distances use the Haversine formula (Earth radius 3,959 miles). Scoring: 100 if rounded miles ≤ 5, else max(0, 100 − (rounded miles − 5)). Counties mode scores by overlap: the percentage of the real county covered by the placed piece (100 for a perfect fit), sampled on a 4-unit grid in map units. Name the county mode: 100 points for naming the right county, 50 for a county that touches it, 0 for any other county or a pass — 1,000 points maximum.
Seeded shuffle: this web version hashes the seed with SHA-256 (WebCrypto) and uses the first 4 bytes as a signed 32-bit integer to drive a mulberry32 PRNG through a Fisher–Yates shuffle of the 241-city pool (or the 36-county pool in either county mode). The Blazor C# version (spec §5) uses the same SHA-256 seed integer with System.Random(seedInt) instead of mulberry32, so the 10 cities picked for a given seed may differ between the JavaScript and C# versions — but the seed format, scoring, and projection are the same.
