Where in the State

Oregon Edition

Ten Oregon cities, one blank map. Tap where you think each city is — the closer your pin, the more points. Full points within 5 miles, then −1 point per mile beyond that.

State

Oregon

Oregon is the only state in v1. More states will be added as data packs — the game itself is built to work for any state.

Seed — same seed, same game

Same seed = same 10 cities, in the same order, for anyone, any time. Share the seed (or the game link) to play the same game as a co-worker. Seeds are case-sensitive.

Map landmarks

Landmarks are for orientation only — they don’t affect scoring. Your choices stay in effect during play.

Game

10 questions. One pin per city, 100 points per question, 1,000 points maximum.

Starting writes the seed into the page’s address, so the link can be shared. Refreshing mid-game restarts that game from question 1 with the same seed.

Projection: equirectangular with cos(44°) correction. Bounds lon −124.716 to −116.314, lat 41.843 to 46.421, viewBox 0 0 1000 757.4. One function projects lon/lat → x/y for drawing; its exact inverse converts taps back. Distances use the Haversine formula (Earth radius 3,959 miles). Scoring: 100 if rounded miles ≤ 5, else max(0, 100 − (rounded miles − 5)).
Seeded shuffle: this web version hashes the seed with SHA-256 (WebCrypto) and uses the first 4 bytes as a signed 32-bit integer to drive a mulberry32 PRNG through a Fisher–Yates shuffle of the 241-city pool. The Blazor C# version (spec §5) uses the same SHA-256 seed integer with System.Random(seedInt) instead of mulberry32, so the 10 cities picked for a given seed may differ between the JavaScript and C# versions — but the seed format, scoring, and projection are the same.
