# Where in the State

A fun learning game: guess where Oregon cities are on a blank map.

**Play it:** https://matt-lane.github.io/where-in-the-state/

First edition: **Oregon**. The game is generic — a state is a data pack, so
other states can be added without changing the game code.

## How to play

You get a blank map of a state, with landmarks (interstates, highways,
rivers, lakes) for orientation, but no city labels.

Each round names one city — "Where is Bend?" — and you click or tap to drop
a pin where you think it is. The game reveals the real location, shows how
far off you were, and awards points.

- 10 questions per game
- **Scoring:** 100 points if you're within 5 miles, then −1 point per mile
  beyond 5, floored at 0. So 5 miles = 100, 6 miles = 99, 10 miles = 95,
  55 miles = 50, and 105+ miles = 0. Maximum 1,000 per game.
- **Seeds:** the city list is shuffled deterministically from a seed, so the
  same seed gives the same 10 cities in the same order for anyone, at any
  time. Share a seed (or a `?state=oregon&seed=…` link) to play the same
  game as a co-worker and compare scores. There's also a daily seed.

## Playable web version

`oregon-geography-game.html` is a standalone playable version of the game
(regenerated by `build-game.py` from the real city and map data in this
repo). Open it in a browser — no server needed.

## Run the Blazor app

The real app is C# with Blazor WebAssembly, in `blazor/`:

```bash
cd blazor
dotnet run
```

See `blazor/README.md` for prerequisites, layout, and how to add a new
state pack. Note: the Blazor build has not been run in every environment —
run `dotnet build` first on your machine.

## What's in this repo

- `blazor/` — the Blazor WebAssembly app (models, seeded shuffle service,
  Haversine + scoring, SVG map component, game pages, and the Oregon
  state pack under `wwwroot/data/`)
- `GAME-SPEC.md` — the full game spec: flow, seeded randomization,
  scoring, map approach (SVG + GeoJSON natively in Blazor), and testing
  checklist
- `oregon-cities.csv` — the city pool: 241 Oregon cities, one per line
- `oregon-cities-with-coords.csv` / `.json` — the same 241 cities with
  latitude/longitude, geocoded via Nominatim / OpenStreetMap
  (see `geocoding-notes.md`)
- `data/oregon/` — Oregon outline GeoJSON (Census 2010) and landmark
  GeoJSON (Natural Earth 10m: interstates, highways, rivers, lakes),
  plus `MAP-DATA-NOTES.md` and `process-map-data.py` to regenerate them
- `geocode.py`, `fix-counties.py` — scripts to re-geocode the city list
  if it changes
- `oregon-geography-game.html`, `build-game.py` — the standalone
  playable web version and the script that builds it from the data above

## Data sources

- City coordinates: Nominatim / OpenStreetMap
- State outline: U.S. Census Bureau, 2010 cartographic boundary
  (public domain)
- Rivers, lakes, roads: Natural Earth 10m (public domain)

Known map gaps: no I-405 (Portland loop), no separate Snake River line
(the eastern border already traces it), major lakes only.
